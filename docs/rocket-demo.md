# 火箭实验室

## 目标与边界

正式页面 `/rocket`（全屏独立，不含站点 Header/Footer），提供可直接观看和操作的实时三维火箭发射演示。按钮控制已经设计好的任务流程，不提供积木编程或火箭搭建功能。旧路径 `/explore`、`/explore/rocket` 重定向到 `/rocket`。

演示任务为两级火箭送卫星入轨，覆盖发射倒计时（3、2、1）、点火建立推力、垂直离台、重力转向爬升、一级分离、整流罩分离、二级推进、卫星释放与绕地运行。时间、距离与部件可见尺寸为教学展示而缩放，不作为真实发射任务的遥测或轨道计算依据。

## 实现原则

- React 承载界面，React Three Fiber / Three.js 渲染三维场景。
- 时间轴是动画的唯一时间来源；UI 低频刷新，三维对象每帧直接更新。
- 暂停、继续、倍速和重置必须同步作用于物体、镜头和特效。
- 流程节点同时是操作按钮：只允许执行当前步骤或重放已完成步骤；后续步骤按顺序解锁。
- 每个阶段播放到下一阶段起点时精确暂停，等待孩子发出下一道指令；即使高倍速或掉帧也不能跨过等待点。绕地运行开始后持续播放。
- 分离部件与卫星从分离点连续运动，不能凭空跳变。
- 三维资源与运行错误明确展示并记录，不能以静态图片冒充正常运行。
- Demo 使用程序化模型与场景验证空间、材质、镜头和完整任务。后续写实资产可以替换模型，保留任务控制接口。

## 浏览器验收

1. 打开 `/explore/rocket`，确认三维发射场和控制界面可见，控制台无新运行错误。
2. 按「启动倒计时」，确认在 00:07 停住；按「点火！」后才建立推力，按「发射升空」后才离开发射台。
3. 播放中点击当前节点暂停，确认任务时间和画面不变；再次点击从原处继续。阶段结束后即使等待或切换倍速，也不能自动执行下一阶段。
4. 依次执行一级分离、整流罩分离、轨道注入、卫星释放，确认每一步都等待指令，部件可辨认。已完成步骤可以重放，后续步骤不能跳过。
5. 到达入轨阶段后继续运行，确认卫星持续绕地运动。
6. 重置后确认回到发射台，分离部件和太阳能板恢复初态。
7. 检查 390px 和 320px 窄屏的流程按钮可用且页面不横向溢出；重新开始和倍速与流程节点在同一控制区。

## 本地运行

```sh
npm install
npm run dev
```

打开终端显示的本地地址并访问 `/explore/rocket`。此模块不依赖 D1 数据库或 API 服务。
