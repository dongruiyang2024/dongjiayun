# 火箭实验室 Demo

## 目标与边界

在探索工坊中提供可直接观看和操作的实时三维火箭发射演示。按钮控制已经设计好的任务流程，不提供积木编程或火箭搭建功能。

演示任务为两级火箭送卫星入轨，覆盖发射倒计时（3、2、1）、点火建立推力、垂直离台、重力转向爬升、一级分离、整流罩分离、二级推进、卫星释放与绕地运行。时间、距离与部件可见尺寸为教学展示而缩放，不作为真实发射任务的遥测或轨道计算依据。

## 实现原则

- React 承载界面，React Three Fiber / Three.js 渲染三维场景。
- 时间轴是动画的唯一时间来源；UI 低频刷新，三维对象每帧直接更新。
- 暂停、继续、倍速和重置必须同步作用于物体、镜头和特效。
- 分离部件与卫星从分离点连续运动，不能凭空跳变。
- 三维资源与运行错误明确展示并记录，不能以静态图片冒充正常运行。
- Demo 使用程序化模型与场景验证空间、材质、镜头和完整任务。后续写实资产可以替换模型，保留任务控制接口。

## 浏览器验收

1. 打开 `/explore/rocket`，确认三维发射场和控制界面可见，控制台无新运行错误。
2. 开始任务，确认计时推进、尾焰出现、火箭离开发射台。
3. 暂停并等待，确认任务时间和画面不变；继续后从原处运行。
4. 查看一级分离、整流罩分离、卫星释放，确认部件可辨认。
5. 到达入轨阶段后继续运行，确认卫星持续绕地运动。
6. 重置后确认回到发射台，分离部件和太阳能板恢复初态。
7. 检查窄屏控制可用且页面不横向溢出。

## 本地运行

```sh
npm install
npm run dev
```

打开终端显示的本地地址并访问 `/explore/rocket`。此模块不依赖 D1 数据库或 API 服务。

## 已执行验证（2026-09-15，自由视角改版）

- 地球自转：`rotation.y` 由任务时间推导（t·0.008），暂停/倍速/重置天然同步；星空开启微闪。
- 入轨拉远完成后（t≥100）相机切换为 OrbitControls：拖动环绕、滚轮缩放（195–1600 单位），目标为地心，可近距离观察卫星；暂停时同样可用。剧本镜头在此之前完全接管，交接无跳变。
- 页面在自由视角阶段显示操作提示胶囊。
- 无头 Chrome 验证：4 倍速到在轨后拖动旋转（画面切换到另一视角）、滚轮缩放（地球拉近）均生效，无 pageerror。
- `node --test src/features/rocket/runtime/mission.test.mjs` 四项测试通过；ESLint 干净；生产构建通过。

早前验证记录：

- 轨迹改全解析：垂直段延长到 9 秒，高度曲线用平移 smoothstep（离台即有初速、快速离塔，燃尽时径向速度归零）；俯仰角由解析导数 atan2(r·dθ, dr) 给出，消除差分噪声。
- 地球从第 0 秒起常驻场景；地面设施 16–28s 淡出，大气穹顶 14–30s 淡出。
- 任务总时长 90s → 120s：爬升段延长到 36 秒；一级与整流罩改为独立弹道（继承速度、重力下翻滚坠地）；爬升中后段镜头俯视。
- 移除 dre­i Sky（画面发白），改为自定义渐变穹顶 shader；辉光后期只留尾焰。
- 本机 Chrome：开始、暂停、继续、4 倍速、阶段跳转、重置、绕地运行和 390px 窄屏检查。
- 暂停时相隔 500ms 的 Canvas 截图逐字节相同；正常流程无浏览器 pageerror。
- 主动模拟 `webglcontextlost` 和地球纹理请求失败：均显示明确错误，停止播放并提供重新加载。
- 本机无头 Chrome 轨道阶段 120 帧采样，中位帧间隔约 16.7ms；这不是其他设备的帧率保证。

仓库全量 ESLint 原有 10 项错误，涉及旧截图脚本、Header、Admin 和 Post，未在本次扩展修复。三维页面为单独延迟加载的模块，生产构建仍会提示该模块体积较大。
